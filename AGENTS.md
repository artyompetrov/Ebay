# Project Agents.md Guide

## О проекте
Мы разрабатываем приложение, помогающее анализировать стоимость товаров на ebay, для последующей их закупки на сайтах типа avito.ru, chipfind.ru и других.

Приложение состоит из нескольких частей:
1. Серверная часть, которая запускается внутри docker (используется docker-compose).
2. Клиентская часть — Blazor WebAssembly приложение.
3. Chrome extension, которая добавляется в браузер и позволяет просматривать страницы ebay, парсить их и сохранять в базу данных по API сервера.
4. В качестве БД используется Postgres — учитывайте ее синтаксис при написании SQL-запросов.
5. В проекте используется кодогенерация клиентов и контроллеров из OpenAPI-контракта.

## Общий стиль кода
При написании кода следуем принципам SOLID, DRY, KISS; стараемся писать структурированный, легко читаемый код, который будет легко поддерживать.

Перед началом работы изучите `src/.editorconfig`, чтобы понимать, какие параметры форматирования и отступов должны использоваться по умолчанию.

Старайтесь избегать копипасты: переиспользуйте существующие методы и расширяйте их при необходимости.

## Навигация по проекту
- `.github/workflows/build-and-tests.yaml` — основная CI/CD-сборка docker-образов и деплой.
- `/src`: исходный код.
  - `/Ebay`: C# backend и Blazor frontend [подробные правила](src/Ebay/AGENTS.md).
  - `/ChromeExtension`: Chrome extension [подробные правила](src/ChromeExtension/AGENTS.md).
  - `Dockerfile`: сборка решения в единый контейнер.
- `/deploy`: docker-compose обвязка для запуска проекта.

## Общий pre-PR чек
Перед отправкой PR используйте `./agent-check.sh` из корня репозитория.
Скрипт запускает базовые проверки сборки и тестов для backend и Chrome extension.

## Актуализация AGENTS.md
Если в рамках задачи изменились правила разработки, структура проекта, процесс сборки/тестирования, кодогенерации, деплоя или другие договоренности, которые должны быть зафиксированы для следующих задач — обновите соответствующий `AGENTS.md` в этом же PR.
