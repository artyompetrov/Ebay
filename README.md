# Ebay

An application for analyzing eBay product prices and subsequent purchasing on external marketplaces.

## Project composition

- **Server** — backend on .NET (Docker / docker-compose).
- **Client** — web UI on Blazor WebAssembly.
- **Chrome extension** — parses eBay pages and saves data via the API.
- **DB** — PostgreSQL.
- Part of the API code is generated from OpenAPI contracts.
