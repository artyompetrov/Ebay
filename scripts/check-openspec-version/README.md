# Check OpenSpec version

`check-openspec-version.sh` verifies that the `openspec` CLI on `PATH` matches the
version pinned in `.openspec-version` (repo root), and that every `openspec-*` skill
under `.claude/skills/` was generated by that same version (the `generatedBy` field
in each `SKILL.md` front matter).

This exists because `openspec update` regenerates skill files to match whatever CLI
version runs it. If the pinned CLI version and the checked-in skills drift apart,
agents end up following instructions for a different CLI version than the one
actually installed. The script fails loudly instead of letting that happen silently.

Used by:
- `scripts/agent-check/agent-check.sh` (local pre-PR check).
- `.github/workflows/build-and-tests.yaml`'s `openspec_validate` job.

To fix a reported mismatch: install the pinned version
(`npm install -g @fission-ai/openspec@$(cat .openspec-version)`), run `openspec update`,
and commit the regenerated skill files.
